# VocabJordan — Aurora Space v6

## تحديث الخلفية الفضائية

تم تطوير خلفية Aurora من v5 إلى مشهد فضائي متحرك مع الإبقاء على واجهة التطبيق ومحتواه التعليمي كما هما.

### المؤثرات الجديدة
- ثلاث طبقات سُدم لونية بنفسجية وسماوية ووردية تتحرك ببطء وتذوب عند الأطراف بقناع بيضاوي.
- طبقة مجرّة بيضاوية خافتة مع حلقات ضوئية بطيئة الحركة.
- ثلاث طبقات نجوم بكثافات وأحجام مختلفة لإعطاء إحساس العمق.
- كوكب بعيد منخفض الظهور مع حلقة مدارية.
- شهب عابرة تظهر على فترات متباعدة.
- الكلمات الإنجليزية العائمة تتحرك بمسارات مختلفة، وتتغير أحجامها تدريجيًا لإعطاء إحساس الاقتراب والابتعاد.

### التوافق والأداء
- 10 كلمات عائمة على الشاشات الكبيرة، و8 على التابلت والهواتف.
- جميع المؤثرات الزخرفية تستخدم `pointer-events: none` وتبقى خلف محتوى التطبيق.
- التحريك مبني على CSS transforms وopacity، دون حلقة JavaScript مستمرة.
- تتوقف جميع الحركات عند إخفاء الصفحة.
- عند تفعيل `prefers-reduced-motion` تبقى الخلفية ساكنة وتُخفى الكلمات والشهب المتحركة.
- لم يتم تعديل بنك المفردات أو الأسئلة أو نظام التعلم والمراجعة أو مفاتيح تخزين تقدم الطالب.

## النشر على GitHub Pages
1. احتفظ بنسخة احتياطية من ملفات الموقع الحالية.
2. ارفع جميع الملفات الموجودة في هذه الحزمة إلى جذر المستودع.
3. لا تغيّر أسماء `index.html` و`manifest.json` و`sw.js` والأيقونات.
4. افتح الموقع مرة واحدة مع الإنترنت بعد النشر كي يتم تثبيت Service Worker وتحديث الملفات المخزنة.

تم رفع اسم ذاكرة التخزين المؤقت إلى `vocabjordan-v14` لإجبار المتصفح على تحميل النسخة الجديدة.

## التخزين
بيانات الطالب تبقى محلية في المتصفح وعلى نفس الجهاز/نطاق الموقع، كما في الإصدار السابق. لم تتم إضافة حسابات أو مزامنة سحابية.

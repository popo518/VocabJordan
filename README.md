# VocabJordan Aurora v7

هذه نسخة محدثة من VocabJordan، وتحافظ على تصميم Aurora Space والميزات السابقة مثل التعلم والامتحانات والمراجعة والإحصائيات والبحث والمفضلة والنطق والخلفية الفضائية.

## التحديثات
- تدقيق بنك الأسئلة السابق (كان 303 سؤالًا) وتصحيح الإجابات والتصنيفات التي ثبت خطؤها.
- إضافة 76 سؤالًا تدريبيًا جديدًا للوحدة الثالثة.
- ربط أسئلة الوحدة الثالثة بأقسام المفردات الصحيحة، بما فيها أقسام الاستماع والنطق والأفعال المالية.
- إدخال مفردات جديدة ضمن أقسام تعلم الوحدة الثالثة حتى لا تبقى الأسئلة بلا محتوى تعلم مطابق.
- تحديث Service Worker إلى `vocabjordan-v15`.

## النشر
ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub Pages بعد حفظ نسخة احتياطية من الإصدار السابق. لا ترفع ملف HTML وحده إذا كنت تريد استمرار التثبيت كتطبيق PWA.

راجع `QA_REPORT.md` للاطلاع على تفاصيل الأخطاء التي صُححت والمواد التي لم تُحوّل إلى أسئلة آلية بسبب نقص السياق أو كونها أسئلة رأي.
